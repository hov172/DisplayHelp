# DisplayHelp 0.6.6 (120)

DisplayHelp 0.6.6 makes saved display setups easier to switch and recover.

### What’s new

- Use system-wide **Favorite 1** and **Favorite 2** shortcuts to open saved profile previews from any app.
- Assign favorites directly from the collapsible **Quick Switch Profiles** section.
- Restore the setup from before the last profile switch, or save and restore an explicit default setup.
- Save profiles for identical monitors when macOS provides distinct display UUIDs. These profiles open in manual preview so you can confirm the numbered screens before applying them.
- Keep profile and language controls stable while read-only display status refreshes run.

The release includes the signed universal macOS installer, user guides, screenshots, example fixes, and checksums.
