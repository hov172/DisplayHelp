# DisplayHelp 0.8.1 (155)

DisplayHelp 0.8.1 is a documentation release. The app itself is unchanged from 0.8.0 apart from the version number.

### What's new

- Every guide was audited against the 0.8.0 code and corrected: README, user guide, FAQ, troubleshooting, rollout, data files and reference notes now describe the Mic row, the Microphone picker, the Output Volume picker, the menu bar icon colors, the Intel EDID Cap backend and the Check for Update network call.
- Screenshots re-rendered from the production views on 0.8.0: menu, layout and favorites, mirrored layout, Output Volume, Microphone, More Controls, data actions, and the Arabic and Traditional Chinese menus. A new strip shows the five menu bar icon states.
- The user guide PDF and Word documents in this release carry the updated text and captures.

The release includes the signed universal macOS installer, user guides, screenshots, example fixes, the MDM profile, and checksums.
