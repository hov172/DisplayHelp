# DisplayHelp 0.6.12 (129)

DisplayHelp 0.6.12 starts self-service installs the moment you click Install.

### What's fixed

- **Install** in the Check for Update dialog sends the request to DisplayHelp Updater immediately. In 0.6.10 and 0.6.11 the "Installing" notice appeared first and the install only began after OK was pressed.

The release includes the signed universal macOS installer, user guides, screenshots, example fixes, the MDM profile, and checksums.
